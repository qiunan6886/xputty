# 参考调研与借鉴点

> 目标：把「SSH / 串口终端客户端」这个品类的成熟交互与 2024–2026 年的现代桌面 UI 语言拆开，只取对 xPuTTY 有用的部分。
> 所有借鉴均重新绘制为 xPuTTY 自己的视觉体系（#0F1115 深色 + #4C8DFF 强调 + 1px 细边），不直接复制截图。

---

## 1. Tabby — 现代终端 + SSH 客户端的标签 / 分屏模型

- 链接：<https://tabby.sh/> ／ 仓库：<https://github.com/Eugeny/tabby>
- 借鉴：
  - **标签页 + 分屏是同级公民**：Tabby 把「split pane」做成标签内的常规操作，而不是隐藏功能，值得直接学习。
  - **会话/配置（Profiles）侧栏**：分组 + 彩色标签 + 快捷启动，对应我们的「生产 / 测试 / 本地串口」树。
  - **克制的深色主题**：几乎纯色分层，靠 1px 描边区分层级，和我们「不用毛玻璃」的约束一致。
- 不照搬：Tabby 的插件市场式入口与 Web 化设置面板（Electron 感重），xPuTTY 保持 Win32 原生窗口与本地设置。

## 2. Windows Terminal — Windows 11 原生标签 / 窗格语言

- 链接：<https://learn.microsoft.com/en-us/windows/terminal/customize-settings/appearance>
- 借鉴（官方文档确认的行为）：
  - `tabWidthMode` 提供 `equal / titleLength / compact` 三种标签宽度策略 → 我们采用 **按标题自适应（titleLength），上限 210px，超出省略号**，保证 5 个中文标签不挤。
  - `showTabsInTitlebar`（标签上移到标题栏）→ 我们保留独立 40px 标题栏 + 38px 标签栏两层，因为还要放品牌、环境指示与命令面板入口。
  - `useAcrylicInTabRow` 默认 `false` → 印证「终端类工具不该用亚克力」，我们用纯色 `#11151B`。
  - `confirmCloseAllTabs`、分屏方向键绑定（`alt+shift+d` 等）→ 关闭多标签二次确认、Ctrl+\ 分屏。
- 不照搬：Windows Terminal 的标签栏高度与图标风格（偏系统图标），我们自绘更细的 1.5px 线条图标与 32px 标签。

## 3. Warp — 输出「块」与命令面板的现代终端体验

- 链接：<https://www.warp.dev/> ／ Block 行为文档：<https://docs.warp.dev/terminal/appearance/blocks-behavior>
- 借鉴：
  - **每条命令一个 Block** 的结构化阅读方式 → 我们在终端里用空行 + 颜色区分「命令 / 输出 / 提示符」三个层级，长日志仍然可扫读。
  - **命令面板（Cmd+K）**：把「新建会话、切换标签、分屏、宏」收敛到一个键盘入口 → 我们标题栏放命令面板按钮，搜索框挂 `Ctrl K`。
  - **排版克制**：正文只有一种等宽字体 + 少量语义色，不用彩色背景块堆叠。
- 不照搬：Warp 的 AI 建议条、渐变品牌色；xPuTTY 面向的是「自有服务器 / 串口设备」的确定性场景。

## 4. Termius — 会话分组、标签与 Snippets（宏的前身）

- 链接：<https://termius.com/>
- 借鉴：
  - **Snippets = 可复用的命令片段**：证明「宏」在 SSH 客户端里是刚需，且需要名称 / 内容 / 快捷键 / 作用范围四要素 → 我们的宏管理弹窗直接按这个信息架构设计。
  - **会话分组 + 彩色标识 + 最近连接**：侧栏树的信息密度参考（我们每行 45px：徽标 + 名称 + host:port + 状态点）。
  - **跨端一致的深色配色**：主色偏冷、语义色只用于状态。
- 不照搬：Termius 的卡片式大圆角（12–16px）与商业版引导位；桌面端我们收紧到 6/8px 圆角以贴近 Win11。

## 5. MobaXterm — 被吐槽的「只有 4 个宏按钮」

- 链接：<https://mobaxterm.mobatek.net/>
- 借鉴（反面教材 + 正面）：
  - 正面：左侧会话树（SSH / Serial / RDP 混排）+ 顶部宏条的产品结构非常高效，是我们信息架构的直接来源。
  - 反面：**宏按钮固定 4 个、不可重命名/排序/配快捷键**，横向分屏上限 2 个 → 这正是 xPuTTY 要解决的两个痛点：**任意数量宏 + 12 种分屏布局**。
  - 反面：图标与字体混用（系统图标 + 位图），导致高 DPI 发虚 → 我们统一 1.5px 内联 SVG，全部矢量。
- 不照搬：MobaXterm 的密集工具栏与多层菜单；xPuTTY 用「标签栏右侧布局组 + 宏条」两处轻量入口替代。

## 6. iTerm2 — 分屏、Profiles 与工具带

- 链接：<https://iterm2.com/>
- 借鉴：
  - **Pane 标题与「最大化窗格」**：iTerm2 每个 pane 有独立标题与最大化/还原，我们把它做成 26px（四窗格 24px）的窗格标题条 + 右上角最大化小按钮。
  - **Split 比例可拖拽、双击复位**：对应我们的 1px 分隔条 + 4px 热区 + 双击 1:1。
  - **Profiles 继承**：会话可覆盖字体/配色/宏，支持后续「全局 vs 当前会话」的宏作用范围。
- 不照搬：iTerm2 的 macOS 风格半透明与复古偏好设置窗口。

## 7. Raycast — 命令面板与快捷键呈现

- 链接：<https://www.raycast.com/>
- 借鉴：
  - **快捷键帽（keycap）的统一画法**：10px 等宽 + 1px 边 + 4px 圆角 + 低对比底色，用在 `Ctrl N`、`Ctrl K`、`Ctrl+Shift+1` 上，让「可键盘操作」一眼可见。
  - **大量列表项的 hover/选中只有两级**（背景亮一级 / 加 1px 内描边），不叠加阴影。
  - **弹窗遮罩不用模糊**，靠降低背景亮度聚焦。
- 不照搬：Raycast 的玻璃质感与超大圆角（我们只在大弹窗用 8px）。

## 8. Linear — 高密度但不拥挤的深色信息层级

- 链接：<https://linear.app/>
- 借鉴：
  - **三级文字色（主 / 次 / 弱）+ 极低饱和背景**：我们用 `#E4E8EF / #9BA5B4 / #697384` 复刻这种层级，让 11 个会话行 + 终端同时存在也不吵。
  - **6px 微圆角 + 1px 边**：按钮、列表选中、徽标全部贯彻。
  - **强调色只出现在「当前动作」**（活动标签顶线、主按钮、焦点环），全屏蓝色面积 < 5%。
- 不照搬：Linear 的浅色主导主题与营销页排版。

## 9. Dribbble — 终端 / 开发者工具的视觉趋势

- 链接：<https://dribbble.com/tags/terminal> ／ <https://dribbble.com/tags/ssh>
- 借鉴：
  - 2024–2026 的终端概念稿普遍采用「**近黑底 + 单一冷强调 + 等宽正文**」，并且把「状态点 / 协议徽标」做成极小尺寸的彩色点缀（6–8px），而不是整行染色。
  - 分屏窗格的标题条倾向 24–28px 的细条 + 极小的工具按钮，而不是整块 toolBar → 我们采用 26/24px。
  - 宏/命令条流行「胶囊按钮 + 彩色圆点」而不是图标按钮 → 宏条采用 28px 胶囊 + 6px 圆点。
- 不照搬：概念稿常见的超大标题、玻璃卡片、3D 渐变背景。

## 10. PuTTY — 需要被现代化的基线

- 链接：<https://www.putty.org/> ／ 内核源码：<https://git.tartarus.org/?p=simon/putty.git>
- 借鉴：
  - 保留其**连接配置的完整度**（会话名、host:port、串口 8-N-1、加密套件信息）→ 状态栏右侧显示 `AES-256-GCM · SSH-2.0`，串口窗格标题显示 `COM3 · 115200 8-N-1`。
  - 保留「**会话即配置**」的心智模型：侧栏每一项就是一份可编辑的 PuTTY 配置，菜单里提供「从 PuTTY 导入会话」。
- 不照搬：PuTTY 的 Win95 风格对话框与 12 个页签的设置窗口；xPuTTY 用「侧栏树 + 单页表单 + 弹窗」替代。

## 11. xterm.js — ANSI 16 色与终端渲染参考

- 链接：<https://xtermjs.org/> ／ 仓库：<https://github.com/xtermjs/xterm.js>
- 借鉴：
  - 其默认主题的 16 色在深色背景下的可读性经过大量终端验证 → 我们的 ANSI 调色板以其为基准做低饱和微调（`#3DD68C` 替代刺眼纯绿，`#F07178` 替代纯红）。
  - 光标块、选区色、滚动条宽度的默认值（光标块 7×14、滚动条 8px 叠加）。
- 不照搬：Web 渲染管线；xPuTTY 走 GDI+/DirectWrite。

## 12. Windows 11 设计语言（Fluent）

- 链接：<https://learn.microsoft.com/en-us/windows/apps/design/>
- 借鉴：
  - 8px 圆角、1px 描边、`#0F1115` 级别的近黑底、Mica 可选但**不用亚克力**；
  - Caption 按钮 46×40、close hover `#E81123`、贴靠布局（Snap Layouts）需要 `WM_NCHITTEST` 返回 `HTMAXBUTTON` → 已写入 DESIGN.md 的实现要点。
- 不照搬：Windows 11 设置页的大面积留白与浅色卡片（终端工具需要更高密度）。

---

## 结论：xPuTTY 的差异化

| 痛点 | 参考对象的现状 | xPuTTY 的解法 |
|---|---|---|
| 宏只有 4 个 | MobaXterm 固定 4 个、不可编辑 | 宏管理弹窗：任意数量（上限 32）、拖拽排序、颜色标签、快捷键、作用范围、自动回车 |
| 横向只能 2 分屏 | MobaXterm 仅左右 2 窗格 | 12 种布局（2×2、1×3、3×1、主从…）+ 拖拽标签到边缘即时分屏 + 窗格最大化 |
| 界面不够精致 | PuTTY / MobaXterm 系统控件拼装 | 自绘标题栏 + 统一 1.5px 图标 + 三级文字色 + 克制的 #4C8DFF 强调，Win11 深色质感 |

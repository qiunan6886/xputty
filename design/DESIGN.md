# xPuTTY 设计规范（v1.0）

> Windows 桌面 SSH / 串口终端管理器 · 深色主题 · 1600×1000 基准
> 本文档配套高保真稿：`mockups/main.html`、`mockups/macro-dialog.html`、`mockups/quad-pane.html`
> 机读 token：`design-tokens.json`（可直接作为 Win32 / GDI+ 取色表）

---

## 1. 设计目标与原则

xPuTTY 是 PuTTY 内核的现代化外壳，用户是运维 / 嵌入式工程师，长时间盯着多台机器。
视觉上要像「Windows 11 原生的专业工具」，而不是网页套壳。

1. **桌面软件质感**：40px 自绘标题栏、1px 分割线、6/8px 圆角、克制的强调色；不使用大面积渐变、毛玻璃、夸张投影。
2. **信息密度优先**：一屏同时容纳会话树 + 5 个标签 + 2 个终端窗格 + 宏条 + 状态栏；留白只服务于分组，不服务于「呼吸感」。
3. **终端是主角**：界面 chrome 永远比终端背景亮一级但更安静（bg1 系），让终端（`#0B0D11`）成为最深的区域，视线自然落进去。
4. **可预期**：所有可点区域有 hover / pressed / focus 三态；危险操作（关闭窗格、删除宏）不与主操作相邻。
5. **GDI+ 可实现**：每个像素都可用「纯色填充 + 圆角路径 + 1px 描边 + 文本绘制」完成，不依赖模糊、阴影模糊半径超过 24px 的效果。

## 2. 基准尺寸与缩放

| 项目 | 规格 |
|---|---|
| 设计基准 | 1600 × 1000（截图 1:1，`--force-device-scale-factor=1`） |
| 最小窗口 | 1180 × 720（低于此宽度侧栏折叠为 48px 图标条） |
| DPI 支持 | 100% / 125% / 150% / 200%，所有 token 数值乘 `scale = LOGPIXELSX / 96` |

## 4. 字体与排版

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| caption | 10 / 14 | 400 | 徽标、快捷键提示 |
| micro | 10.5 / 15 | 400 | 状态栏、分组计数、面板标签 |
| bodySm | 11.5 / 16 | 400 | 侧栏 host、说明文字、弹窗 desc |
| body | 12.5 / 18 | 400 | 会话名、按钮、标签页 |
| bodyStrong | 12.5 / 18 | 600 | 活动会话名、活动标签 |
| titleSm | 13 / 19 | 600 | 标题栏应用名、窗格标题 |
| title | 15 / 22 | 600 | 弹窗标题「宏管理」 |
| mono-terminal | 13 / 20 | 400 | 终端正文（Cascadia Mono，字宽 ≈ 7.8px） |
| mono-code | 12 / 19 | 400 | 弹窗「发送内容」 |

- 标题栏应用名 13/600；版本号 `v0.85.1` 用 10px 等宽 + `bg2` 底 + 4px 圆角。

## 5. 圆角、阴影、间距、动效

**圆角**：`4`（徽标、小按钮、快捷键帽）/ `6`（按钮、输入框、选中行、标签顶角）/ `8`（面板卡片、弹窗、提示卡）。窗口本身由系统处理圆角，不在自绘范围。

**阴影**（GDI+ 用 32 位 ARGB 纯色叠加或省略）：

| Token | 值 | 用途 |
|---|---|---|
| sm | `0 1px 2px rgba(0,0,0,.45)` | 按钮、徽标 |
| md | `0 8px 24px rgba(0,0,0,.45)` | 下拉、浮层 |
| lg | `0 18px 48px rgba(0,0,0,.55)` | 弹窗 |
| focus | `0 0 0 3px rgba(76,141,255,.14)` | 输入聚焦光晕（直接画半透明圆角矩形） |

**间距刻度（4 的倍数）**：2 / 4 / 6 / 8 / 10 / 12 / 16 / 20 / 24 / 32。
常用组合：控件内边距 10×0；控件间距 6–8；分组间距 12–16；面板内边距 12–18。

**动效**：

| 场景 | 时长 | 曲线 |
|---|---|---|
| hover / 颜色变化 | 100ms | ease-out |
| 折叠展开、面板滑出 | 160ms | cubic-bezier(.2,0,0,1) |
| 弹窗出现（缩放 .98→1 + 透明度） | 180ms | cubic-bezier(.2,0,0,1) |
| 标签拖动插入指示 | 即时（0ms） | — |
| 光标闪烁 | 530ms 亮 / 530ms 暗 | step |

## 6. 图标规范

- 16×16 视觉网格，实际渲染 12 / 14 / 16 三档；线宽 **1.5px**（12px 时可用 1.25 视觉补偿），圆角端点 `round`。
- 颜色一律 `currentColor`，由文字色控制；不填色（仅状态点、拖拽手柄用实心圆）。
- 图标语义固定：`server`=SSH、`plug`=串口、`terminal`=本地 Shell、`grid`=2×2、`split-v/h`=分屏方向、`maximize`=最大化窗格、`drag`=拖动排序、`record`=录制快捷键。
- 实现：SVG path 可 1:1 转为 GDI+ `GraphicsPath`（`MoveTo/LineTo/AddArc`），或使用系统自带 `Segoe Fluent Icons` 对应码位替代（推荐后者以减小体积，需保持同一视觉重量）。

## 7. 组件规格

### 7.1 自定义标题栏（40px）

- 左：22×22 品牌块（`#4C8DFF → #3A76E0` 轻竖向渐变，圆角 6，内含白色 `>_` 线稿）+ `xPuTTY` 13/600 + 版本徽标。
- 分隔线 1×16 `#252C36`；环境指示：6px 绿点（外圈 12% halo）+ `生产环境` 600 + 计数 `4 个会话 · 2 个窗格`（11px secondary）。
- 右：命令面板、设置两个 30×26 透明图标按钮（hover `rgba(255,255,255,.06)`），分隔线，三个 caption 按钮 **46×40**：最小化 / 最大化 / 关闭。close hover 背景 `#E81123`、图标转白。
- 交互：空白区拖动窗口；双击最大化；最大化后双击还原；右键出系统菜单（WM_NCHITTEST 返回 HTCAPTION，caption 按钮返回 HTMINBUTTON/HTMAXBUTTON/HTCLOSE 以支持 Win11 贴靠布局）。

### 7.2 会话侧栏（240px）

- 背景 `#101319`，右 1px `border`。
- **新建会话**按钮：34px 高，实心强调渐变 + 1px `#2F63C7`，圆角 6，右侧快捷键帽 `Ctrl N`（半透明白描边）。
- 搜索框：32px，`#0D1015` 底、`#262D38` 描边、圆角 6；左放大镜 14px；占位「搜索会话或主机」（12px tertiary）；右侧 `Ctrl K` 帽。
- 分组头：27px，chevron 12 + folder 14 + 名称 12/600 + 计数 10 等宽 + 右侧 hover 出现的「+」。
- 会话行：45px，内边距 0 8；协议徽标 32×17（SSH 蓝 / SERIAL 青 / LOCAL 紫，8px 700）；名称 12.5 + host:port 10.5 等宽次级；右侧 6px 状态点（online 绿 + halo / idle 黄 / off 灰）。
- 选中行：`#182234` 底 + 内 1px `#2B3D57` + 左侧 2×27 强调条（圆角 2）。
- 底部：提示卡（62px，`#141920` 底，灯泡图标 + 两行说明），3 个 27px 底部链接（串口扫描 / 密钥与凭据 / 从 PuTTY 导入）。
- 交互：分组可折叠（160ms）；行 hover `#171D26`；右键菜单（连接 / 复制会话 / 编辑 / 删除）；拖拽会话到分组改归属；搜索实时过滤并高亮匹配文本。

### 7.3 标签栏（38px）

- 背景 `#11151B`，底部 1px `#1E242D`；标签沿底部对齐（高 32），圆角 `6 6 0 0`。
- 标签内容：协议图标 14 + 名称 12（最大 150px 省略号）+ 关闭 16×16（hover 底色 `rgba(255,255,255,.08)`）。
- 活动标签：背景 = 终端色 `#0B0D11`、1px `#242B35` 描边（不含下边）、**顶部 2px 强调条**（左右内缩 8，圆角 2），文字 `#EEF2F8` 600。
- 非活动：透明底、secondary 文字；hover 背景 `#1A2029`。
- 尾部：`+` 新建标签 26×26；右侧「分屏」标签 10.5px + 4 个 26×20 布局按钮（`#0D1015` 底、1px 边、活动 `#23304A` + 内 1px 30% 强调）+ 更多 `⋯`。
- 交互：单击切换；中键关闭；拖动重排（显示 2px 强调插入线）；拖到终端区边缘 → 生成分屏；Ctrl+Tab 循环；宽度 > 8 个时尾部出现溢出列表。

### 7.4 终端窗格

- 窗格标题条 26px（四窗格 24px）：状态点 6 + `prod-web-01` 11/600 + `/` + `ssh ops@10.0.0.21:22` 10 等宽；环境旗标 `生产`（红 13% 底）/`串口`（青 11% 底）/`跳板`（黄 13% 底）；右侧 20×18 工具：拆分 / 最大化 / 关闭。
- 终端正文：内边距 9–12，`mono 13/20`，`#C3CCD9`；自动换行关闭（超宽水平滚动或按列宽截断），滚动条 8px 叠加、3px 圆角、hover 变亮。
- 窗格焦点：内 1px `rgba(76,141,255,.4)` 描边（四窗格时必现，单/双窗格可用标题文字提亮代替）。
- 窗格底部右下角可叠加只读徽标（如 `COM3 · RX 1.24 KB · TX 96 B`）：18px 高、`#10151B` 92% 底、9.5px 等宽 tertiary。
- 1px 分隔线 `#272F3A`；四窗格间距同为 1px（`calc(50% - 1px)`）。

### 7.5 宏工具条（44px）

- 左：键盘图标 12 + 「宏」10.5/600/字距 .6（`#7C8798`）。
- 宏按钮：28px 高、内边距 0 10、`#171C24` 底 + 1px `#262E39`、圆角 6、文字 12；左侧 6px 圆点（颜色即标签色）；hover 背景 `#1E2531` + 边 `#3A4658` + 文字提亮（100ms）。
- 末尾「+ 配置宏」：透明底 + 1px 虚线 `#34405A` + 文字 `#8FB8FF`。
- 右侧：`Ctrl+Shift+1~8 触发` 10.5px tertiary + 分隔 + 「宏管理」（齿轮/滑杆图标）。
- 交互：hover 显示 tooltip（名称 + 快捷键 + 作用范围）；单击发送到焦点窗格（按下态 80% 亮度，60ms）；右键菜单（编辑 / 复制 / 禁用 / 删除 / 排序）；拖拽按钮重排（与弹窗列表双向同步）；过多时横向滚动或折叠为「更多宏 ▾」。

### 7.6 状态栏（26px）

- 背景 `#0C0F14`，顶 1px `#1E242D`，11px 文字。
- 左：连接点 + `已连接`（`#C2CBD8`）+ 分隔 + 会话名（等宽）+ 分隔 + `SSH · 10.0.0.21:22`。
- 中：`UTF-8`、`xterm-256color`、`80×24`、`LF`（等宽、tertiary）。
- 右：3 格延迟条 + `12 ms`（<50ms 绿 / 50–150 黄 / >150 红）+ 锁图标 + `AES-256-GCM · SSH-2.0` + `缓冲 734 行`。
- 交互：延迟每 2s 刷新；点击延迟区打开连接详情浮层；点击缓冲行数跳到终端底部。

## 8. GDI+ 实现要点

1. **双缓冲**：整窗 `BeginBufferedPaint` 或位图双缓冲，避免窗格重绘撕裂；终端区域单独失效（`InvalidateRect` 只刷对应窗格）。
2. **圆角矩形**：`GraphicsPath::AddArc` 四角，半径 4/6/8；1px 描边用 `Pen`，为对齐像素坐标 +0.5（如 `DrawRectangle(x+0.5, y+0.5, w-1, h-1)`）。
3. **文本**：UI 用 `DrawString` + `StringFormat`（`TrimmingEllipsisCharacter`、`NoWrap`、`TextRenderingHintClearTypeGridFit`）；终端建议 DirectWrite（`IDWriteTextLayout` 逐行或整屏纹理）以保证等宽与性能。
4. **颜色转换**：token 的 `#RRGGBB` → `Color(255, r, g, b)`；半透明用 `Color(alpha, r, g, b)`，遮罩直接用 `FillRectangle`。
5. **图标**：SVG path → `GraphicsPath` 静态缓存；stroke 1.5 → `Pen(width=1.5f)` + `LineJoinRound`、`StartCap/EndCapRound`。
6. **悬停与动画**：`TrackMouseEvent(TME_LEAVE)` 管理 hover 状态；120ms 动画用 `SetTimer(15ms)` 插值颜色（线性 RGB 插值即可，避免 HSL）。
7. **缩放**：所有尺寸经 `Scale(int v) = MulDiv(v, dpi, 96)`；字体用 `Gdiplus::Font(..., UnitPixel)` 并按 scale 计算像素值。
8. **不需要实现**：亚克力/云母背景、实时模糊、复杂投影；弹窗阴影可用一张预渲染的 9-slice 半透明位图（32px 模糊度）替代实时高斯模糊。
9. **性能红线**：终端滚动/输出时不得整窗重绘；状态栏延迟条只在数值变化时刷新；拖拽分屏时用虚线预览（DrawFocusRect 或 1px 高亮线），松手后才重排布局。

### 12.5 使用规范

- **透明区域**：圆角外必须透明（ICO 帧带 Alpha），不得填白底或黑底方块。
- **不要**给图标加文字、外发光、投影、3D 效果；不要非等比拉伸；最小使用尺寸 16px。
- 深色任务栏 / 浅色任务栏均可用：深底靠 1px 内描边保持轮廓，浅底见 `logo-preview.png` 的对比示意。
- **与标题栏标记的关系（已定稿）**：应用图标 = 深底 + 渐变符号（满足 shell 图标规范）；标题栏 22px 品牌标记 = 强调色渐变圆角块（`#5B98FF → #3A76E0`）+ 白色 `>_`（避免深底在深标题栏上“消失”，22px 下对比更强）。两者共享同一符号几何，按场景各用一版，不再互换。
- **单色 / 高对比场景**（未来需要时）：将符号改为 `#E4E8EF`，底改为 `#12151A`，去除渐变即可，几何不变。

### 12.6 兼容性验证

ICO 内所有 9 帧均使用 **32bit BMP 条目**（非 PNG 压缩条目）：PNG 帧在 Explorer 中可用，但 `System.Drawing.Icon`、`csc /win32icon`、部分 WiX 流程对 PNG 帧支持参差，全 BMP 可保证安装包与编译器取图标时都能正确读取（文件约 372 KB，Windows 图标缓存可接受）。

已验证：
- Pillow 重新读取 9 帧尺寸正确；
- .NET `System.Drawing.Icon` 逐尺寸解码 16~128 正常（GDI+ 请求 256 时会回退到 128，属 .NET Framework 限制，不影响 Explorer/WIC）；
- WPF/WIC `BitmapDecoder` 解码 9 帧（含 256×256），且 256 帧与源图逐像素一致（max diff = 0）；
- shell32 `ExtractIconEx` 可直接取到 32×32 / 16×16 帧（Explorer、快捷方式、任务栏走同一条取图标路径）。
